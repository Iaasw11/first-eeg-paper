# Thesis Reuse

本目录用于记录当前SCI研究未来如何复用为数字媒体技术本科毕业论文。

当前原则：**不单独启动毕业设计开发，不占用首篇论文窗口期。**

未来重点记录：

- 哪些科研内容可直接转为本科毕业论文核心章节；
- 哪些算法模块可封装为系统服务；
- 哪些结果图表可复用；
- 如果学院要求更偏数字媒体技术，可增加哪些交互/可视化层；
- Unity / Web / 桌面端的可行系统形态；
- 答辩时需要补足的系统测试与交互设计证据。

## 当前候选扩展

- EEG波形与脑区信息可视化
- 运动意图识别结果实时展示
- 置信度与训练历史反馈
- 康复动作动画或虚拟场景
- 老年友好型交互界面

> 只有当SCI研究主线基本完成后，才开始决定是否实现这些功能。
